# /packages

Published npm packages for the Khameleon design system.

<!-- SYNC: When files in this directory change, update this document. -->

| Directory | Package                 | Purpose                                                                |
| --------- | ----------------------- | ---------------------------------------------------------------------- |
| `core/`   | `@khameleon/core`    | Core UI components, theme system, and utilities                        |
| `cli/`    | `@khameleon/cli`     | CLI tooling: component docs, templates, scaffolding, codemods          |
| `build/`  | `@khameleon/build`   | Build plugins for StyleX source builds (Babel, PostCSS, Vite)          |
| `themes/` | `@khameleon/theme-*` | Visual themes (default, neutral, daily, brutalist, meta, whatsapp)     |
| `vega/`   | `@khameleon/vega`    | Vega/Vega-Lite chart wrapper (canary only)                             |
| `charts/` | `@khameleon/charts`  | Chart components — themeable wrappers over a peer engine (canary only) |
| `lab/`    | —                       | Experimental components (not published)                                |
